# PostKit Roadmap

## Phase 1 — Project Setup & Foundation ✅

- Project scaffolding (Vite + React + TypeScript)
- Chrome Extension Manifest V3 configuration
- Tailwind CSS v4 setup
- All four extension surfaces registered (popup, side panel, background, content)
- Development environment with HMR
- Documentation

## Phase 2 — Side Panel UI

- Post editor interface
- Character count and LinkedIn formatting preview
- Settings panel (API key configuration)
- Dark theme design system

## Phase 3 — AI Integration

- Groq cloud API client
- Ollama local API client
- AI provider selection (local vs. cloud)
- Post generation from topic/idea input
- Tone and style controls

## Phase 4 — LinkedIn Integration

- Content script DOM interaction
- Post insertion into LinkedIn editor
- Page context reading (draft detection)

## Phase 5 — Templates & Drafts

- Post template system
- Draft auto-save via Chrome Storage
- Template library management

## Phase 6 — Polish & Launch

- Error handling and edge cases
- Performance optimization
- Final UI polish
- Chrome Web Store packaging (if desired)
